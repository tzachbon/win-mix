# Common software-license comparison

**Snapshot:** 2026-09-21. All licenses below permit commercial use and distribution; the main differences are conditions and what must be shared when distributing covered code. This is a high-level comparison; the linked license text controls.

| License | Copyleft and main redistribution conditions |
| --- | --- |
| [MIT](https://choosealicense.com/licenses/mit/) | No copyleft. Keep the copyright and license notice in copies or substantial portions; source disclosure is not required. |
| [Apache 2.0](https://choosealicense.com/licenses/apache-2.0/) | No copyleft. Preserve required notices, mark changed files, and pass through any applicable `NOTICE` text. Contributors grant an express patent license. |
| [BSD 2-Clause](https://choosealicense.com/licenses/bsd-2-clause/) / [BSD 3-Clause](https://choosealicense.com/licenses/bsd-3-clause/) | No copyleft. Preserve copyright, conditions, and disclaimer in source and binary distributions. BSD 3-Clause adds a prohibition on using contributor names to endorse derived products without permission. |
| [GPL-2.0](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html) / [GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html) ([GitHub summaries](https://choosealicense.com/licenses/gpl-2.0/), [v3](https://choosealicense.com/licenses/gpl-3.0/)) | Strong copyleft: when distributing a covered modified/combined work, provide corresponding source and license the covered work under the applicable GPL version. Merely using or privately modifying code without distributing it does not trigger that source-sharing condition. GPLv3 adds more explicit patent and user-product installation terms. |
| [LGPL-3.0](https://www.gnu.org/licenses/lgpl-3.0.html) ([GitHub summary](https://choosealicense.com/licenses/lgpl-3.0/)) | Weak copyleft: distributed modifications to the LGPL library remain under LGPL. An application that uses the library may use other terms, subject to notice and relinking/replacement requirements when distributing the combined executable. |
| [MPL-2.0](https://www.mozilla.org/en-US/MPL/2.0/) ([GitHub summary](https://choosealicense.com/licenses/mpl-2.0/)) | File-level copyleft: distributed modifications to MPL-covered files remain under MPL and their source must be available. Other files in a larger work may use different terms. |
| [AGPL-3.0](https://www.gnu.org/licenses/agpl-3.0.html) ([GitHub summary](https://choosealicense.com/licenses/agpl-3.0/)) | GPL-style copyleft for distributed covered works, plus a network-use trigger: users interacting remotely with a modified network-service version must be offered its corresponding source. |

Unlike every license in this table, [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0) limits permitted use and redistribution to noncommercial purposes, so it does not grant a general right to commercial internal use or commercial distribution.

**Sources:** GitHub's [Choose a License](https://choosealicense.com/) summaries and linked texts; GNU's official [GPLv2](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html), [GPLv3](https://www.gnu.org/licenses/gpl-3.0.html), [LGPLv3](https://www.gnu.org/licenses/lgpl-3.0.html), and [AGPLv3](https://www.gnu.org/licenses/agpl-3.0.html) texts; Mozilla's [MPL 2.0](https://www.mozilla.org/en-US/MPL/2.0/) text. No popularity ranking is included.
